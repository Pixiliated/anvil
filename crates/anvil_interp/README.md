# anvil-lang-interp

The Anvil language's reference interpreter, which defines what programs mean.

Part of [Anvil](https://crates.io/crates/anvil-lang), a compiled language built to be written by AI agents. Install the `anvil` command with `cargo install anvil-lang`; this crate is one of its parts and has no stable API of its own yet.
