# Anvil branding

The mark is an anvil with a glowing `>` above its face, the metal being forged, which also reads
as a terminal prompt. Sparks fly off to the right. Every file here is generated by
`build_anvil.py`: polygons with rounded corners, so straight lines and circular arcs only, with no
gradients, strokes or fonts. The wordmark is drawn, not typeset.

## Files

| File | Use |
|---|---|
| `icon.svg` | App icon and avatar: the mark on a slate rounded square |
| `mark-on-dark.svg`, `mark-on-light.svg` | The mark alone, transparent, for dark or light backgrounds |
| `mark-mono-on-dark.svg`, `mark-mono-on-light.svg` | One-colour mark (steel on dark, slate on light) |
| `lockup-on-dark.svg`, `lockup-on-light.svg` | Mark and "anvil" wordmark side by side, transparent |
| `small/*-16.svg`, `small/*-32.svg` | Separate drawings for 16 px and 32 px, fitted to the pixel grid |
| `png/<name>/<name>-<px>.png` | Exports at 16, 32, 64, 128, 256, 512 and 1024 px (lockups at 800 and 1600) |
| `preview.png` | Contact sheet of every version and size, on light and dark |

At 16 px and 32 px, use the `small/` drawings (or the PNGs made from them); scaling down the
512 px master blurs the chevron and sparks.

## Colours

| Name | Hex | Role |
|---|---|---|
| Slate | `#1E2630` | Icon background; ink on light backgrounds |
| Steel | `#E9EDF1` | The anvil and wordmark on dark backgrounds |
| Forge orange | `#FF6A1A` | The chevron and one spark |
| Spark gold | `#FFB020` | The other sparks |

## Rebuilding

```bash
pip install resvg-py pillow
python build_anvil.py
```

This rewrites every file here except this README. The output is deterministic: the same script
gives byte-identical files.
